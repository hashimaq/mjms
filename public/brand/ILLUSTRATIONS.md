# MJMS decorative illustrations

**All fashion graphics:** filled monocolor product silhouettes in `src/components/brand/fashion-product-icons.tsx` (marquee, ambient, category decor).

**Motion:** Framer Motion in `MjmsAmbientFashionMotion.tsx`, lazy-loaded via `MjmsAmbientBackgroundLoader.tsx`.

**Optional SVG Repo CC0 swap:** `public/brand/fashion-svg/SOURCES.md`.

**License:** All artwork is original to this repository (no third-party stock in the current build).

**Delivery:** Inline SVG + code-split JS for motion — no extra image HTTP requests.

**Brand colors:** Strokes use CSS `currentColor` tinted via `#5F4F92`, `#6FB0B0`, `#1F5AA6`, `#E3B233` (see `mjms-illustration-field.css`).
